# V10C: lesion matching by functional damage, exploratory sensitivity

2026-11-09. This analysis is explicitly **post hoc** to V10B and is not confirmatory. V10B 150 random lesions showed that the grokking-late group resists the same physical knockout better; to assess *repair speed* conditional on **similar immediate functional deficit**, choose a NEW, disjoint set of masks and match on initial validation damage alone.

**Fixed design before searching V10C masks:** in each of 5 paired networks, generate 1000 distinct random masks via mask-seeds 1001..2000 removing exactly 150/300 (50%) hidden units, same indices in both models. Determine immediate **validation** damage without repair. Retain masks with both groups suffering **10..40 percentage points** accuracy loss and absolute difference of initial val damage <=5pp. Preselect first at most 5 acceptable masks per model seed by ascending mask seed. Never select masks based on subsequent recovery, validation AUC, or test performance. If none in seed, report missing matches. These masks are disjoint from V10B (101..105). Checkpoint fixed at 8000.

**Repair experiment:** equal AdamW fresh lr.001 wd0, cross entropy on exactly the original 500 training samples, 400 updates. Each group has own unlesioned continuation. Compute exact area of difference from no-lesion val/test control; initial damage and time to two consecutive val>=.99 (and test>=.99). The untouched test at this stage is a *secondary* check; it was already logged during train V10B, so NOT a sealed confirmation. Independent units are network seeds (N<=5); masks within seed nested. When few matched masks, label uncertain and do not generalize.

**Sensitivity limitation:** selecting on validation loss may create collider bias in a causal estimate; this analysis asks about conditional recoverability under approximately matched injury severity, not total effect of randomly ablating an equivalent neuronal fraction. Equal initial accuracy loss does not guarantee the same affected cases, CE, functional mechanisms, or gradient geometry. Distinct L1 regimes remain direct confounders.
