# N36 · Auditoría de una segunda fuente independiente

**Fecha:** 28/10/2026. **Alcance:** verificación de acceso y estructura, NO validación del modelo sobre muestra externa.

1. **Essex Ortega (2018)**: [registro institucional](https://researchdata.essex.ac.uk/85/), licencia CC BY 4.0, `AnonymizedData.xlsx` 67 kB, fecha 2018, experimento de campo y aprobación ética. URL verificable de archivo `https://researchdata.essex.ac.uk/85/1/AnonymizedData.xlsx`. Apertura desde web devuelve error de `unsupported content-type` para XLSX; descarga a contenedor falla por resolución DNS. **No se inspeccionaron bytes, columnas ni resultados**. No afirmar que tenga interacciones diádicas completas.
2. **Mixmosa**: [fuente pública, repositorio de CSV originales](https://github.com/dankras/mixmosa-anonymized-data). Acceso real por GitHub verificado a `csv/interactions.csv`, `csv/swiping.csv`, `csv/user_features.csv`, `csv/events.csv`; huellas blob en [resultados](AGGREGATE_RESULTS_REPAIRED.json). 1.895 fechas completas, 30 eventos, 410 participantes, 259 aceptaciones mutuas; la portada habla de 2.961 citas y está pendiente reconciliar cobertura entre tablas. Sin licencia explícita en archivo `LICENSE` del repositorio según navegación de raíz; los registros individualizados se conservan solo en fuente original y no se republican en el proyecto.
3. **Columbia / OpenML, dataset`s/speed-dating`**: [repositorio GitHub](https://github.com/datasets/speed-dating), experimentos 2002–2004 con valoraciones por cita y deseo de repetir. `data/speed-dating.csv` existe como blob sha `7a39a97ed38fdc388b55a79e54c167e95552dabb`, pero la acción de acceso devolvió contenido vacío para ese archivo; no se puede afirmar análisis de datos. La licencia del distribuidor `PDDL` está descrita como «assuming either no rights or public domain» y requiere revisión de derechos en origen.
4. **keithmcnulty/speed_dating**: CSV [`speed_data_data.csv`](https://github.com/keithmcnulty/speed_dating/blob/master/speed_data_data.csv) accesible (427.919 caracteres, blob `239a05b5ca40bbb746ee12c27de61327a3ffd953`), pero contiene solo variables agregadas de filas tales como `gender,age,income,goal,career,dec,attr,...`, sin identificadores cruzables visibles de ambos miembros; por sí solo **NO permite** contraste de parejas recíprocas o homogamia diádica. Podría servir para preferencias individuales de segunda muestra tras verificar procedencia.
5. **eHarmony, Brian McFee**: [página de datos](https://brianmcfee.net/data/eharmony.html) describe dos periodos con archivos `EH-*-data.csv.gz` (características anonimizadas/obfuscadas) y `EH-*-labels.csv.gz` (etiqueta positiva/negativa de pares ID1,ID2). Enlaces de descargas directas devuelven `unsupported content-type: application/gzip` en la herramienta web, y entorno de contenedor tiene acceso de red DNS bloqueado. Ningún byte inspeccionado. Además las variables obfuscadas no pueden tratarse como educación o belleza.
6. **Pablo-Arias/speed_dating**: contiene código de un estudio de mímica facial y enlaces a archivos en Archive.org; repositorio por sí solo no trae los datos diádicos ni un control equivalente del modelo.

**R5:** ya hay un dataset empírico diádico utilizable (Mixmosa), pero una segunda fuente suficiente para replicación **no ha sido analizada**. Continuar con la misma muestra después de ver resultados para ajustar el algoritmo tiene rendimiento inferencial decreciente. Puerta siguiente: datos en origen accesibles y comprobación de campos/consentimiento antes de nuevo ciclo confirmatorio. Sin reclamar validez española.
