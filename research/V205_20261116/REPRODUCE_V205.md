Para repetirla, extraer V205_EVIDENCE.zip en un directorio nuevo y usarlo como BASE. No ejecutar los publicadores, preparadores de registro ni verificadores de GitHub para reproducir la ciencia.

Entorno original: Python3.12.16, NumPy2.5.4, PyTorch2.11.0+cu128, SymPy1.14.0, Matplotlib y Node24.16.0. No se necesita CUDA para esta prueba. Antes de iniciar Python, fijar OPENBLAS_NUM_THREADS, OMP_NUM_THREADS y MKL_NUM_THREADS en2; el ejecutor principal limita afinidad y prioridad en Windows. En otros sistemas revisar research_resource_limits.py para adaptar solo ese límite operativo y documentar el cambio; no cambiar el juego o las pérdidas.
